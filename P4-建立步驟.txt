SENPlus+ Academy Ultra P4 第一階段建立步驟

1. 在 Supabase SQL Editor 開啟 New query。
2. 貼上並執行 supabase/p4-core-setup.sql。
3. 建立新的公開 GitHub repository：senplus-academy-ultra-p4。
4. 把本 ZIP 解壓後的檔案上載到新 repository。
   如 GitHub 提示超過100個檔案，可分批上載；不要把 ZIP 本身放入 repository。
5. 在 Vercel 匯入 senplus-academy-ultra-p4，建立獨立 P4 網址。
6. 開啟新網址，首次登入及五科卡片是否正常。

本階段已完成：
- P4 獨立網站名稱及藍色／黃色主題
- P4 學生註冊與跨年級登入保護
- P4 五科及課程範疇資料庫骨架
- 管理員只顯示 P4 學生與 P4 學習紀錄
- P4 專用題庫品質統計
- 保留家長連結、忘記密碼、錯題分析及手機／平板改善
